Reseller API

Sell our products on your own bot or website. Every order is charged to your wallet points balance and delivered instantly from our stock.

🔑 Getting your API key

Open the bot and tap 🔑 Reseller API → Generate API Key. Your key is shown only once — save it immediately. It is linked to your wallet: orders are paid from your points balance, so top up with 💎 Buy Points before you start selling.

If you lose your key, generate a new one in the bot (the old one stops working). An admin can also deactivate a key at any time.

Authentication

Send your key in the X-API-Key header on every request. There is no other auth.

X-API-Key: YOUR_API_KEY_HERE

Base URL: https://telegram.toolsbydcx.com/api

Endpoints

GET /api/products

Lists all active products for the bot your key belongs to, with live available stock.

curl -H "X-API-Key: YOUR_API_KEY_HERE" \
  https://telegram.toolsbydcx.com/api/products

GET /api/stock

Check live stock before ordering. product_id is required.

curl -H "X-API-Key: YOUR_API_KEY_HERE" \
  "https://telegram.toolsbydcx.com/api/stock?product_id=1"
{
  "product_id": 1,
  "name": "100M Credit API Codex 5 Days",
  "price_usd": 5.5,
  "status": "active",
  "stock": 12
}

POST /api/order

Buys qty of a product, charges your wallet total_usd × points_rate points ($1 = 10 points by default), and delivers instantly. qty must be 1–100.

curl -X POST -H "X-API-Key: YOUR_API_KEY_HERE" \
  -H "Content-Type: application/json" \
  -d '{"product_id": 1, "qty": 2}' \
  https://telegram.toolsbydcx.com/api/order

Response (qty ≤ 9 — contents inline)

{
  "order_id": 42,
  "product_id": 1,
  "product": "100M Credit API Codex 5 Days",
  "qty": 2,
  "total_usd": 11.0,
  "points_charged": 110.0,
  "status": "delivered",
  "contents": [
    "CODEX-XXXX-1111",
    "CODEX-XXXX-2222"
  ]
}

Response (qty > 9 — file via Telegram)

For 10 or more items the contents are not returned inline. Instead the delivery file is sent to you on Telegram by the bot, and the response says so:

{
  "order_id": 43,
  "product_id": 1,
  "product": "100M Credit API Codex 5 Days",
  "qty": 10,
  "total_usd": 55.0,
  "points_charged": 550.0,
  "status": "delivered",
  "contents": null,
  "note": "10+ items: the delivery file was sent to you on Telegram."
}
⚠️ Treat delivered contents as secret. Each code/account is sold once — do not share or resell the same item twice. If a code does not work, open a warranty claim in the bot with the order ID.

Errors

Errors are always JSON {"error": "..."} with an HTTP status code:

CodeMeaning
400Bad input — missing/invalid product_id, qty out of range, or invalid JSON.
401Missing, invalid, deactivated, or banned API key.
402Insufficient points — top up your wallet in the bot and retry. Nothing was charged.
404Product, order, or endpoint not found (orders only return your own).
409Out of stock — the product is out of stock or has fewer items than the qty requested. If points were charged, they are refunded automatically.

Tips

  • Call GET /api/stock before a big order — stock changes as other resellers buy.
  • Keep your key secret. Anyone with it can spend your wallet balance.
  • Need help? Open a support ticket in the bot and include the order ID.
